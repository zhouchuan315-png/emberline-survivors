# 余烬防线 / Emberline Survivors

Cocos Creator 3.8.6，2D 俯视角单人生存肉鸽。目标：在三种难度战区坚守 12 / 16 / 20 波，击败感染源后撤离，并用战斗所得金币持续成长。

## 核心循环
移动躲避 → 自动锁定射击 → 管理弹匣/换弹 → 拾取经验 → 暂停战斗并三选一升级 → 构筑强化 → 首领战 → 金币结算 → 营地购买永久天赋 / 开局道具 → 选择更难战区。
WASD / 方向键移动，空格冲刺，Esc 暂停，数字 1/2/3 选择升级。触屏提供虚拟摇杆与冲刺按钮。
普通感染者、快速感染者、重型感染者和最终首领，加喷吐、自爆、冲锋、召唤四种特殊怪；有碰撞推开、伤害无敌帧、掉落、冲刺冷却。营地可选择三名幸存者：烬火（均衡突击）、夜隼（高速侦察）和白芷（高生命 / 再生医师），角色属性进入规则层并随局保存。

## 视觉基线
环境与怪物采用手绘漫画废土，不采用像素画。主角改为清晰线稿、赛璐璐上色的成年二次元女性：烬火为栗红短马尾 / 橙金突击夹克，夜隼为银白短发 / 青色侦察夹克，白芷为浅亚麻短发 / 白色医师夹克。三人都穿完整战术服、长裤与战靴，保持原职业、ID、属性与存档。暗灰混凝土和橄榄绿为环境色，芥末橙为火力，感染体使用苔绿色，经验使用冷青绿色，伤害用暗红。
场地中部低对比、边缘布置废弃工业设施；人物轮廓清晰。UI 使用深色战术面板、暖白文字、橙色行动按钮。避免无意义霓虹装饰。
AI 背景与角色由用户指定的素材 V2 服务生成；纯色背景角色在本地抠底，逐张检查 alpha 和游戏中的边缘。
首页专用 `roster/cover-wide.png`（1920×1080）与 `cover-tall.png`（900×1600）均以三名角色本轮原画为参考生成。横版左侧保留文字区、右侧为三人主视觉；竖版上部保留面部、下方放操作区。选人头像直接取同一角色原画的高清裁图，不放大 256px 动作帧。原画批次 `70026473-9435-4c46-b9ce-2fd9070e97e4`，封面批次 `49b30e7c-97c2-4a05-bb1f-b28e486e4cc5`，合计 5 张、回执 1.10 元。生成、抠底、rig、接触表、首尾循环 / 透明边检查在 `evidence/materials-20260928-anime-heroes/`；Web 实机证据在 `evidence/runtime-anime-heroes-20260928/`。枪口火焰按新模型锚点绘制，曳光在起点短暂补偿高度后回到敌人受击平面，不修改规则碰撞坐标。桌面图标转换改用新烬火头像，既有 ZIP 仍为历史发行。
三名主角使用独立的 16 帧全身连续持枪移动图集 `roster/*-run.png`：头部、头发、肩膀、枪械、髋部和双腿来自固定镜头动作视频，统一缩放与横向构图，脚底落在同一基线，不做逐帧包围盒缩放。每 104 世界单位完成一个两步周期，按实际位移推进，暂停冻结、撞边界停步、倒退反向、冲刺保持前倾姿势。`*-idle`、`*-reload`、`*-fire` 分别承载待机呼吸、换弹和射击后坐力；枪口闪光仍由运行时特效绘制。当前素材脚本是 `scripts/prepare-fullbody-motion.py`，QA 是 `scripts/fullbody-motion-qa.py`，源 / 证据在 `evidence/materials-20260928-fullbody-motion/`；旧步态脚本仅是历史轮次。旧 `animation/survivor*.png` 和 `art/survivor.png` 不再由运行时加载。
僵尸保留 4 个不同步态关键姿势，每姿势保持两帧；角色攻击/站立开枪与倒地各 4 帧。移动中开枪保持步态并叠加轻微后坐力。快速怪提高播放速率，重型怪降低速率；朝左镜像，不称为八方向动画。
角色图集每格 256×256，脚底基线 y=232，Cocos 禁止 trim；AI 画出的非等距分隔线按逐格审核边界去除。基础角色和 Boss 图集的 0–7 帧是旧移动姿势，8–11 帧是站立 / 攻击 / 施法，12–15 帧是倒地；Boss 仍只循环前 8 帧移动。三名主角移动改用专用 `*-run` 图集的完整 16 帧，站立、攻击和倒地才使用基础图集，不能混用帧索引。Boss 帧已在实际导出中分别验证移动、蓄力和死亡状态。不能仅以整张图集生成成功认定动画合格。
枪口火焰/命中/死亡烟尘/脚步尘各 4 帧，配合粒子、伤害数字、残影和冲击波；反馈通过可消费的一次性战斗事件触发，不消耗游戏 RNG。暂停冻结动作与特效；玩家死亡先播放 0.62 秒倒地再显示结算。
程序绘制的子弹、经验、范围圈和 UI 进度条属于可读性优先的功能几何。自动步枪默认 18 发弹匣，按 R 或触屏按钮可提前换弹，打空后自动换弹；换弹期间可以移动和冲刺，暂停或升级会冻结换弹进度。快速敌人为基础感染者的速度/尺寸/颜色变体；三张战区使用独立 Boss 模型：铁狱暴君、熔炉屠夫和零号母巢。每个 Boss 有 66% / 33% 两个阈值，分为三阶段，阶段切换会清理旧技能并显示 HUD 反馈。技能包括震地重锤、锁向冲锋、扇射、落火 / 毒池、召唤虫群和环形弹幕；所有技能先生成可读预警区域或方向，再消费固定战斗事件表现。

## 拼接关卡与碰撞（2026-09-24）
普通地图为固定工业隔离区：2400×1440，4×3 个 600×480 区域，每区域由 5×4 个 120×120 地面块拼接，总计 240 块。24 个道具独立摆放，包括仓储集装箱、物资箱、路障和废车；主要道路贯通，初始位置为中央十字路口。镜头跟随角色并限制在地图内，小地图显示玩家、障碍和附近感染者。

落地凸多边形是真实碰撞范围；人物使用脚下圆，半径 16。采用不超过 8 单位的位移分步和圆/多边形投影，冲刺、怪物击退与相互挤压都必须复用相同移动函数。圆角扫掠检测子弹最早障碍交点；穿甲弹可穿敌人，不能穿实体掩体。索敌与近战接触检查视线；经验吸附也不能隔墙拾取。电磁脉冲保留范围技能行为。强化池包含弹匣/换弹、弹速、护甲、暴击、减速、击杀回血和尾弹增伤，三选一过滤已满层项目。

寻路使用按体型分组的 40 单位网格，缓存静态连通边与朝玩家的反向距离场；清晰视线时直接追击，遇障碍时使用可见的低距离节点。人物与独立道具按脚底/落地点 Y 排序。B 切换碰撞轮廓方便编辑验收；不是第二套规则。

场景素材来自指定服务的新批次；低对比地面做周期处理，4 类物体按品红色度抠底，不以亮度删除高光。每种图片的落地几何按实际产物标注。道路、分区标线和围边为程序绘制。场景为运行时组装的 Cocos 节点，入口仍为 Main.scene。当前不包含无尽分块加载、可破坏掩体或建筑室内。

## 工程边界
规则置于无引擎依赖的 TypeScript 模块，Cocos 负责节点、渲染、资源、输入和音频。网页版使用真实 Cocos 构建。
首版为完整可玩原型，暂不包含广告、付费、联网、云存档和原生商店打包。

2026-09-28 桌面发行使用 Electron 44.4.5 封装同一份 Cocos Web 导出，目标为 Windows 10/11 x64、macOS 13+ arm64 / x64。
`desktop/main.cjs` 用安全标准协议 `emberline://game` 读取包内文件，不启动 HTTP 服务；渲染器启用沙箱、隔离上下文且不能访问 Node。
固定应用数据目录 `EmberlineSurvivors` 与固定来源保证更新包后仍可读取金币、天赋、道具和选择；与旧浏览器试玩存档独立。
Mac 使用 ad hoc 本地签名，不启用需要 Team ID 的 hardened library validation；公开发行仍需 Developer ID 签名和公证。Windows 包未签名。
`scripts/package-desktop.mjs` 只打包桌面启动器与 Cocos 导出，不把源码证据、开发依赖或用户存档放进包。
图标仅从现有 `art/survivor.png` 转换 ICO / ICNS，无远端素材提交。新发行 hash 与真实包验收在 `evidence/desktop-20260928/`。

## 弹匣与构筑（2026-09-24）

步枪默认 18 发，换弹 1.55 秒，备弹无限；每次散射齐射只消耗 1 发。打空自动换弹，R / 右侧触屏按钮提前换弹。换弹期间暂停射击，允许移动和冲刺；升级/暂停冻结计时，结束后填满当前容量，重开重新初始化武器。HUD 显示当前弹量、容量、换弹倒计时/进度，脚下同步小进度条。

新增扩容弹匣、快手换弹、高速弹头、防爆护甲、弱点识别、冷凝弹头、生命回收、尾弹过载，共 17 类强化；数值和上限以 `Simulation.ts` 的 UPGRADES 为准。暴击使用模拟 RNG，每次齐射共享一次判定；冷凝减速 1.5 秒，重复命中刷新持续时间、不反复叠乘；击杀回血每个敌人只结算一次。最后 3 发增伤可叠加散射和暴击。升级快手换弹保留当前完成比例，扩容在换弹完成时使用新容量。

运行证据 `evidence/runtime-weapon-20260924/`；`scripts/weapon-runtime-qa.cjs` 在独立浏览器中验证实际 Cocos 导出。沿用现有图片/音效，换弹与强化反馈通过程序绘制和一次性事件实现，无新增素材费用。

## 多战区与局外成长（2026-09-24）

`Campaign.ts` 定义三种地图难度：普通仓储区 12 波（300 秒）、困难熔铸厂 16 波（400 秒）、噩梦研究所 20 波（500 秒），每波 25 秒，最终波生成首领；必须满足坚守时间、最终首领击杀和场上剩余精英清理。生命 / 攻击 / 速度 / 密度 / 金币倍率均按战区配置，逐波继续增长。当前局外成长使用三名角色各自的 6 节点、2 分支天赋树和 4 种消耗道具；代码单一来源为 `Progression.ts` 与 `HeroTalents.ts`。

四类新怪均有独立 16 帧资源：前 8 帧行进、4 帧攻击、4 帧倒地。喷吐者保持距离并用锁定方向的酸液射击；自爆者 1.1 秒预警后爆炸；冲锋者 0.8 秒预警后直线冲刺，不能穿墙；召唤者 1.2 秒施法后生成两只疾行者，受数量上限和冷却约束。AI 图集必须按各自原图边界分格；喷吐者的分隔线、冲锋者相邻行脚部残片已在本地派生中修正。32 格图标分别用于局内技能和营地商品；冰霜 / 脉冲 / 治疗 / 爆炸特效按每行共享比例保留膨胀与消散变化。
