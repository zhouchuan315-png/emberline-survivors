# 余烬防线 · Emberline Survivors

“闪避布雷”已换成生成的金属感应雷素材，带连续布防亮灯和待机呼吸动画，升级卡显示同款地雷。冲刺布雷后引诱追兵触发爆炸。新素材、生成过程与预览见 `evidence/materials-20260929-mines/`；桌面 / 手机实机报告见 `evidence/runtime-mines-20260929/`。

基于 **Cocos Creator 3.8.6 + TypeScript** 的单人打僵尸生存肉鸽原型。游戏目录：`emberline-survivors`。

选择普通、困难或噩梦战区，坚守 12 / 16 / 20 波并消灭最终感染源并清理剩余精英后撤离。击杀、完成波次和胜利获得金币，金币按当前奖励的 68% 累计以提高局外成长难度；失败保留已赚金币。每个角色拥有独立天赋树，可在营地用金币解锁，另有独立的开局道具页；旧商店通用天赋已移除。每局重新抽取升级组合，局内强化在结束后清空，永久成长保存在本机。

## 已有玩法

- 3 张 2400×1440 拼接地图，每张 12 个区域、240 块地面，分别有 24 / 30 / 36 个实体障碍，镜头跟随与小地图。
- 自动步枪索敌、18 发弹匣、手动/自动换弹、快速子弹碰撞、击退、命中闪光、掉落粒子与音效。
- 玩家、冲刺和僵尸与障碍碰撞；僵尸按体型绕路，子弹被掩体阻挡，自动索敌过滤被遮挡目标。
- 8 类敌人：普通、疾行、重装、感染源首领，以及喷吐、自爆、冲锋和召唤感染者；特殊攻击带提前预警。
- 12 / 16 / 20 波逐步提高血量、速度和密度；熔铸厂有热区、研究所有毒区，难度越高金币奖励越多。
- 烬火、夜隼、白芷各有 6 个角色专属天赋节点，分成 2 条三节点分支；前两层最多 3 阶，末端节点提供开局技能。4 种开局消耗道具可装备其中一件。
- 经验吸附、升级三选一、每局 2 次重抽和联动图鉴；26 类强化，包括爆破弹、连锁电弧、连杀狂热，以及散射、脉冲、爆破的 3 阶进化。
- 英雄 3 / 6 / 9 级觉醒：烬火换弹后爆裂齐射，夜隼冲刺释放穿透弹幕，白芷治疗清弹新星。
- 中途小 Boss：普通第 4 / 8 波，困难第 4 / 8 / 12 波，噩梦第 4 / 8 / 12 / 16 波；铁甲先锋、炉火督军、孢群卫士轮换登场，独立两阶段、血条与金币 / 治疗补给。
- Boss 登场有全屏淡红警告、红色边缘和名称提示；最终 Boss 提高生命、伤害与移速，三阶段包含加速逼近和近身砸地。
- 冲刺、短暂无敌、冷却提示、暂停、失败/胜利结算、重开。
- 键盘、鼠标及触屏摇杆；竖屏跟随角色显示战场。
- 声音开关与减弱震动/闪烁设置。
- 角色逐帧行走/奔跑、站立开枪、僵尸攻击和倒地；移动射击保留步态并叠加后坐力。
- 三名二次元女性主角：橙金突击手烬火、银发青色侦察兵夜隼、白衣战地医师白芷；横版 / 竖版首页使用同一人物设定的新封面。
- 枪口火焰、命中爆点、伤害数字、死亡烟尘、脚步扬尘、冲刺残影、升级光圈，以及技能图集特效；爆破弹、连锁电弧使用生成图集，连杀狂热与英雄觉醒使用实时着色器光环。

## 打开工程

在 Cocos Dashboard 里导入本目录，选择 **3.8.6**。打开 `assets/scenes/Main.scene`，点击预览。
场景的 Game 节点挂载 Emberline 组件，运行时生成 Canvas、战场和 UI。素材在 `assets/resources/`，可在 Creator 中查看。

## 构建与试玩

```bash
cd emberline-survivors
npm install
npm test
npm run build
npm run typecheck
npm run preview
```

本地网址：**http://127.0.0.1:8765**。`npm run preview` 为每次启动分配独立试玩路径（自动跳转），所有文件返回开发期 `no-store` 响应头并禁用条件缓存，避免旧 Cocos JS 和素材缓存。重新构建后刷新页面即可加载新产物。
构建脚本默认使用 `/Applications/Cocos/Creator/3.8.6/CocosCreator.app/Contents/MacOS/CocosCreator`。其他安装位置可通过环境变量 `CREATOR_BIN` 指定。
首次类型检查需要 Creator 导入或构建生成 `temp/tsconfig.cocos.json`。`skipLibCheck` 只跳过引擎声明文件本身的兼容问题，游戏源码仍启用 strict 检查。

## 操作

桌面离线发行包见 `dist/desktop/`：Windows x64、macOS Apple Silicon 和 macOS Intel 三版。
Windows 完整解压后运行 `EmberlineSurvivors.exe`；Mac 解压后将 `Emberline Survivors.app` 放入“应用程序”。
系统要求、存档位置与签名说明见 [desktop/README.txt](desktop/README.txt)。桌面存档与浏览器试玩独立。

在 macOS 上重新打包全部版本：`npm run package:desktop`。需要 Node.js 22.12+、Python 3 / Pillow、Cocos Creator 3.8.6；
脚本重新构建 Cocos 后使用固定版本 Electron 44.4.5 封装，输出带校验和的 ZIP，不依赖预览服务器。
已有刚构建的 Web 导出可运行 `npm run package:desktop:existing`。打包产物不加入源码版本管理。
验证：`node scripts/verify-desktop.mjs` 检查三个包；`node scripts/desktop-runtime-qa.cjs` 在 Apple Silicon Mac 上实际启动解压包。
运行验证使用隔离存档，需要 Playwright 和 pngjs；`PLAYWRIGHT_PATH` 可指定已有依赖。

## 当前范围

这是可继续开发的完整玩法原型。已针对桌面浏览器与手机尺寸浏览器验证；尚未制作 Android/iOS 原生包、微信小游戏包、广告/付费系统、联网玩法或云存档。战斗场景为可探索的三张固定拼接地图。所有独立障碍都有落地多边形碰撞，外边界封闭；当前障碍不可破坏，地图不是无限生成。首页采用三名二次元主角的新横版 / 竖版插画。

## 弹匣与强化

默认弹匣 18 发，换弹耗时 1.55 秒，备弹无限。按 R / 点击换弹可提前补满，打空自动换弹；换弹时停止射击，仍可移动与冲刺。暂停和升级冻结换弹进度；重开清空局内强化，并根据永久天赋与本次开局道具恢复容量和满弹匣。散射齐射只消耗 1 发弹药。

升级仍为随机三选一，已满层强化不再出现。新增 8 种强化：

| 强化 | 每层效果 | 上限 |
|---|---|---|
| 扩容弹匣 | 容量 +6，未换弹时立即补 6 发 | 5 |
| 快手换弹 | 换弹耗时乘以 0.78 | 5 |
| 高速弹头 | 弹速 +20% | 4 |
| 防爆护甲 | 所有伤害减免 +12 个百分点 | 4 |
| 弱点识别 | 暴击率 +12 个百分点，双倍子弹伤害 | 5 |
| 冷凝弹头 | 命中减速 +15 个百分点，持续 1.5 秒；重复命中刷新 | 3 |
| 生命回收 | 每次击杀恢复 0.8 生命，不超过生命上限 | 4 |
| 尾弹过载 | 弹匣最后 3 发伤害 +35%，可叠加散射和暴击 | 3 |

换弹中选择扩容会在本次换弹结束时装入新容量；选择快手换弹会缩短剩余时长，保留完成百分比。按 `node scripts/weapon-runtime-qa.cjs` 验收实际导出，不将测试 fixture 加入游戏入口。本轮沿用现有图片与音效，无素材生成费用。

## 战区与营地成长（2026-09-24）

| 战区 | 难度 / 波数 | 最短坚守时间 | 地图机制 | 金币倍率 |

## 强化流派与联动（2026-09-29）

局内强化扩展为 26 种。每局免费重抽 2 次，升级时按 Q / 点击重抽，不消耗经验或金币；候选足够时三张全部替换。正常升级尽量提供火力、已拥有强化和配套联动候选。满层强化不再出现，重开恢复次数。

| 新强化（最多 3 阶） | 玩法与逐阶效果 |
|---|---|
| 换弹震爆 | 消耗至少半个弹匣后完成换弹，120 / 140 / 160 范围内造成 210% / 270% / 330% 武器伤害 |
| 闪避布雷 | 冲刺起点放置 1 / 2 / 3 枚地雷，0.45 秒布防，存留 6 秒；每枚造成 180% / 220% / 260% 武器伤害；最多同时 9 枚 |
| 冰霜碎裂 | 子弹至少减速 20%；子弹击杀减速敌人时冰爆，范围 85 / 100 / 115，造成 105% / 140% / 175% 武器伤害；范围伤害不递归触发 |
| 寻敌跳弹 | 主弹最多弹射 1 / 2 / 3 次，寻找 220 范围内未命中的目标，每跳保留 72% 伤害；不继承爆破、电弧或猎首触发 |
| 再充能护盾 | 28 / 40 / 52 护盾，选择时充满；6 秒未受击后 2 秒内充满；护甲先减伤、护盾再吸收，溢出伤害扣生命 |
| 猎首标记 | 同一敌人 2 秒内连续受到 3 次主弹命中，引爆 140% / 200% / 260% 武器伤害，对大小 Boss 乘 1.5；散射副弹不积层 |

联动所需两项均达到 **2 阶** 后自动激活，可以同时拥有多组：

- 换弹震爆 + 快手换弹 → **装填清场**：震爆同时清除范围内敌弹。
- 闪避布雷 + 爆破弹 → **爆裂雷区**：地雷范围 +35、伤害 +40%。
- 冰霜碎裂 + 冷凝弹头 → **凛冬蔓延**：冰爆给范围内敌人施加 55% 减速，持续 2.5 秒。
- 寻敌跳弹 + 连锁电弧 → **超导跳弹**：跳弹每跳保留 90% 伤害。
- 再充能护盾 + 电磁脉冲 → **雷盾反击**：破盾时释放 170 范围 / 220% 武器伤害脉冲，充能等待缩短至 4 秒。

升级卡显示联动提示；升级 / 暂停时可点击联动图鉴或按 Tab 查看所需阶数、完成度及效果。图鉴不推进模拟。战斗中仅添加脚下护盾细条、地雷小标记和敌人三格猎首标记；不新增遮挡战场的大面板。所有范围伤害、跳弹、清弹遵守场景碰撞视线。沿用现有特效与图标，无远端素材提交。
